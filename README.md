# Alongside Frontend

The public frontend for Alongside.

The frontend is a React application built with Vite. It communicates with the Alongside backend through the application interfaces defined by the private Alongside repository.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
